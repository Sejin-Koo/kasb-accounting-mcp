# 세법 및 중소기업회계기준 조회 가이드 (회계팀용)

이 문서는 **새로 개발한 것이 없습니다.** 이미 연결되어 있는 Korean-law-mcp(법제처
국가법령정보센터 기반)를 회계팀이 세법·중소기업회계기준 조회에 바로 쓸 수 있도록
정리한 사용 가이드입니다. K-IFRS·일반기업회계기준·기타기준서·질의회신은
`kasb-accounting-mcp`(이 저장소의 나머지 부분)를 사용하세요.

## 1. 왜 별도 개발이 필요 없는가

2026-07-21 실제 호출로 확인한 사실:

- Korean-law-mcp는 `search_law` / `get_law_text`로 **법률·시행령·시행규칙**을 실시간
  조회합니다. 법인세법을 예로 들면 법률(001563)·시행령(003608)·시행규칙(007229)이 각각
  별도 조회되고, 개정 이력(시행예정본 포함)까지 자동으로 표시됩니다.
- 중소기업회계기준은 상법 시행령 제15조제3호에 따라 **법무부가 고시**한 것으로, KASB
  사이트가 아니라 법제처의 **행정규칙**으로 등록되어 있습니다(행정규칙일련번호
  2000000022226). `discover_tools` → `search_admin_rule` / `get_admin_rule`로 전문까지
  실시간 조회가 확인되었습니다(아래 예시 참고).

## 2. 세법 조회 방법

```
search_law(query="법인세법")
  → 법령ID/MST 확보 (법률/시행령/시행규칙 각각 별도)
get_law_text(mst="<확보한 MST>", jo="제23조")   # 특정 조문만 조회할 때
get_law_text(mst="<확보한 MST>")                 # 전문 조회
```

복합 질문(예: "2024년 개정으로 뭐가 바뀌었나", "관세법 체계 전체", "과세처분 불복 절차")은
`legal_research`에 `task` 파라미터(amendment_track/law_system/dispute_prep 등)를 지정해
한 번에 조회하는 것이 더 정확합니다.

### 회계팀이 자주 찾는 세법 목록 (검색어 그대로 사용)

| 구분 | 검색어(search_law query) | 비고 |
|---|---|---|
| 법인세 | `법인세법` | 시행령·시행규칙 함께 조회됨 |
| 소득세 | `소득세법` | |
| 부가가치세 | `부가가치세법` | |
| 국세 통칙 | `국세기본법` | 경정청구, 부과제척기간 등 |
| 국세 징수 | `국세징수법` | |
| 조세 특례·감면 | `조세특례제한법` | 통합투자세액공제 등 개정이 잦음 → `legal_research`의 `amendment_track` 권장 |
| 상속·증여 | `상속세및증여세법` | |
| 지방세 | `지방세법`, `지방세특례제한법` | |
| 국제조세 | `국제조세조정에관한법률` | 이전가격, CFC 등 |
| 외부감사 | `주식회사등의외부감사에관한법률` | 외감법. 상장/비상장 감사인 지정 등 |

### 확인된 사용 예시 (2026-07-21 실제 조회 결과)

```
search_law(query="법인세법")
→ 법인세법 [현행] 법령ID 001563 / MST 280349 (공포 2025-12-23, 시행 2026-07-01)
  법인세법 시행령 [현행] 법령ID 003608 / MST 283635
  법인세법 시행규칙 [현행] 법령ID 007229 / MST 287787
  🔜 시행예정 개정: 2027-01-01, 2028-01-01 시행분 이력까지 자동 표시됨
```

## 3. 중소기업회계기준 조회 방법

db.kasb.or.kr에는 없으므로 아래 순서로 조회합니다.

```
discover_tools(intent="행정규칙")
  → search_admin_rule, get_admin_rule 확인
search_admin_rule(query="중소기업회계기준")
  → "중소기업회계기준 고시" / 행정규칙일련번호 2000000022226 / 공포 2013-02-01 / 소관 법무부
get_admin_rule(id="2000000022226")   ⚠️ 반드시 "행정규칙일련번호"를 id로 넣을 것
  → 전문(제1장 총칙 ~ 제10장 주석, 부칙, 별표 목록) 조회됨
```

**주의 (2026-07-21 실제 확인한 함정):** 검색 결과에는 "행정규칙ID"(41522)와
"행정규칙일련번호"(2000000022226) 두 개의 숫자가 함께 표시되는데, `get_admin_rule`의
`id` 파라미터에는 **행정규칙일련번호**를 넣어야 합니다. 행정규칙ID(41522)를 넣으면
`[NOT_FOUND]` 오류가 발생합니다(법제처 API 자체의 제약이 아니라 파라미터를 잘못
넣은 경우였음 — 41522 대신 2000000022226으로 재시도하면 정상 조회됩니다).

## 4. 참고 — 이번 조사에서 함께 확인한 사항

- `search_admin_rule`은 `knd` 파라미터로 훈령(1)/예규(2)/고시(3) 종류를 필터링할 수
  있습니다(중소기업회계기준은 고시).
- `compare_admin_rule_old_new`로 중소기업회계기준의 신구조문 대비도 가능합니다
  (개정 시 변경사항 파악에 유용).
